TikTok

      
Usa a API oficial do TikTok (Content Posting API). Você cria um app grátis no TikTok for Developers uma única vez.

      

        
        
        
      

      

        
        
        
      

      

        Não voltou sozinho? Colar código
        

      

      
Padrão para postar automático

      

        
        
      

      

        Como criar o app do TikTok (passo a passo)
        
    
          
  1. Suba este projeto no GitHub e ative o GitHub Pages (Settings → Pages → Branch main, pasta /docs). Sua Redirect URI será https://SEU-USUARIO.github.io/NOME-DO-REPO/callback.html.
    2. 
          
  2. Entre em developers.tiktok.com → Manage apps → Connect an app.
    3. 
          
  3. Adicione os produtos Login Kit e Content Posting API (ative Direct Post).
    4. 
          
  4. Em Scopes, marque user.info.basic, video.upload e video.publish.
    5. 
          
  5. Em Login Kit → Redirect URI, cole a URL do passo 1.
    6. 
          
  6. Copie o Client Key e o Client Secret para cá, salve e clique em Conectar TikTok.
    7. 
        

        
⚠ Enquanto o app não passar pela revisão do TikTok, o postar direto só publica como privado ("Só eu"). O modo rascunho funciona: o vídeo chega no seu TikTok e você toca em publicar.

      

    


    

      
Instagram

      
Posta Reels pela API oficial da Meta. Precisa de conta Profissional (Criador ou Empresa) ligada a uma Página do Facebook.

      

        
        
        
        
        
      

      

        
        
      

      

        Como gerar o token do Instagram (passo a passo)
        
    
          
  1. No app do Instagram, troque para conta profissional e ligue a uma Página do Facebook.
    2. 
          
  2. Entre em developers.facebook.com → Meus apps → Criar app (tipo Empresa) e adicione o produto Instagram (configuração com Login do Facebook para Empresas).
    3. 
          
  3. Copie o App ID e o App Secret (Configurações → Básico) para cá.
    4. 
          
  4. Abra o Graph API Explorer, escolha o seu app e adicione as permissões: instagram_basic, instagram_content_publish, pages_show_list, pages_read_engagement, business_management.
    5. 
          
  5. Clique em Generate Access Token, autorize, copie o token e cole aqui. O Lab troca por um token de 60 dias.
    6. 
        

        
Enquanto o app estiver em modo de desenvolvimento, ele funciona para a sua própria conta (você é administrador do app). Depois de 60 dias, gere um token novo e conecte de novo.
